IMPORTANT BEFORE ANDROID APK BUILD
This is the Android packaging preparation ZIP, not an APK. PWABuilder/Bubblewrap Trusted Web Activity packaging requires this app to be published at a public HTTPS URL that you control. The app's local budget data remains in the browser/app storage on that device; it is not cloud-synced. The app must be opened once online to load/cache its files before offline use.

DATA SAFETY
- Export a JSON backup before changing app versions or devices.
- Browser/app data clearing can erase locally stored information.
- Keep the exported JSON backup somewhere safe.
- Keep the Android signing keystore and passwords safe; future updates need the same signing identity.

APP STORE
Google Play submission requires a Google Play developer account and AAB package. A direct APK can be shared for testing outside Play Store.
