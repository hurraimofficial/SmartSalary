Privacy Notice

SmartSalary is an offline-first personal budgeting, expense tracking, and payroll tool. It does not require an account, phone number, password, cloud sync, Google sign-in, or internet connection for normal operation.

1. Local Data Storage

All your monthly salary records, budget allocations, daily expenses, payroll details, salary advances, attendance bonus calculations, and savings goals are stored locally in your browser's private local storage on this device only. The app does not transmit, harvest, or send any of your financial data to external servers or third parties.

2. Backups & Data Portability

You can export a JSON backup file anytime. Because that backup file contains your personal budgeting information, keep it in a secure location. Importing a backup file restores your saved records safely without cloud interaction.

3. User Responsibility

Clearing browser site data, resetting the browser, or losing the device may delete locally stored records unless you have exported a JSON backup. Always export backups periodically. SmartSalary does not hold, process, or transfer real money; it is purely a personal budgeting utility.
